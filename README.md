# Accounting Reports App (React + Express)

A full-stack accounting application for real-time Profit & Loss and Balance Sheet generation.

## Prerequisites
- Node.js

## Quick Start

### 1. Server (Backend)
Runs on port 5000.
```bash
cd server
npm install
npm start
```

### 2. Client (Frontend)
Runs on port 5173.
```bash
cd client
npm install
npm run dev
```

## Features
-   **Double Entry**: Ensures Debits = Credits.
-   **Real-time Reports**: Reports update immediately upon adding transactions.
-   **Premium UI**: Built with Tailwind CSS.
